## The word

**peekaboo**

Home Wi-Fi plays peekaboo: full bars one second, gone the next, back
again the moment you stop looking for it. One word, no context needed —
everyone who has ever watched the signal vanish mid-call knows the game.
It is the truest thing about the router in the corner: it is there, and
then it very much is not, and then it is again, as if nothing happened.

## How it works

`main.ts` writes the single word to `/output/entry.txt` (8 characters,
no trailing newline). Run it with:

```sh
node main.ts
```
